Set up on your iPhone

First, open this page in Safari and copy its address from the address bar. You'll paste it in shortcut 2. Make sure it ends with ?app=instagram.

Shortcut 1: "Gremlin Release" (runs when the Gremlin lets you through)

  1. Shortcuts app → Shortcuts tab → +. Name it exactly Gremlin Release.
  2. Add action Text, type open.
  3. Add action Save File. Turn Ask Where to Save off, set the path to gremlin-grace.txt and turn Overwrite If File Exists on.
  4. Add action Open App → Instagram.

Shortcut 2: the automation (runs every time Instagram opens)

  1. Shortcuts → Automation tab → + → App → choose Instagram, tick Is Opened, pick Run Immediately → Next → New Blank Automation.
  2. Add Get File. Set path gremlin-grace.txt and turn Error If Not Found off.
  3. Add Get Details of Files → Last Modified Date.
  4. Add Get Time Between Dates: between Last Modified Date and Current Date, in Minutes.
  5. Add If: Time Between Dates is less than 10 → put Stop This Shortcut inside (that's your 10-minute free pass).
  6. After End If, add Open URLs with this page's address.

Then open Instagram. The Gremlin should appear. When it gives up, tap Go to Instagram: that runs Shortcut 1, which starts the 10-minute pass and opens Instagram without blocking you again.

I couldn't test these shortcut steps on a real iPhone from here. If a step looks different on your phone, screenshot it and send it over.
