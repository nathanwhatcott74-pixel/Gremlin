Set up on your iPhone

Shortcut 1: "Gremlin Release" (runs when you choose to open Instagram anyway)

  1. Shortcuts app → Shortcuts tab → +. Name it exactly Gremlin Release.
  2. Add action Text, type open.
  3. Add action Save File. Turn Ask Where to Save off, set the path to gremlin-grace.txt and turn Overwrite If File Exists on.
  4. Add action Open App → Instagram.

Shortcut 2: the automation (runs every time Instagram opens)

  1. Shortcuts → Automation tab → + → App → Instagram, tick Is Opened, choose Run Immediately → Next → New Blank Automation.
  2. Add Get File: path gremlin-grace.txt, turn Error If Not Found off.
  3. Add Get Details of Files → Last Modified Date.
  4. Add Get Time Between Dates: between Last Modified Date and Current Date, in Minutes.
  5. Add If: Time Between Dates is less than 10 → put Stop This Shortcut inside (your 10-minute free pass).
  6. After End If, add Open URLs:
    https://nathanwhatcott74-pixel.github.io/Gremlin/?app=instagram

These steps haven't been tested on a real iPhone yet. If a menu looks different, screenshot it.
